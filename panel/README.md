# Magic Trackpad settings panel

Adapted November 17, 2026 from the WinUI 3 control panel in vitoplantamura/MagicTrackpad2ForWindows, commit 3392291af4814efb33d0d2b8b99948eca33a77a1 (release v2.3). Distributed under the accompanying GPLv2 license.

The Windows x64 build groups click modes together, uses adaptive controls and native expanders, includes optional opening motion, and revises the English labels and battery status. Other languages use the original translations. Build the complete MSI with the repository root Build.ps1.
