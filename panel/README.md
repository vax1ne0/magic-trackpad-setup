# Magic Trackpad settings panel

Adapted November 17, 2026 from the WinUI 3 control panel in vitoplantamura/MagicTrackpad2ForWindows, commit 3392291af4814efb33d0d2b8b99948eca33a77a1 (release v2.3). Distributed under the accompanying GPLv2 license.

The Windows x64 build groups click modes together, uses adaptive controls and native expanders, includes optional opening motion, and revises the English labels and battery status. The panel also includes Arabic with a right-to-left layout. Build the complete MSI with the repository root Build.ps1.

The separate press and release controls draw on [qqzlqqzlqqzl’s haptic controls](https://github.com/qqzlqqzlqqzl/MagicTrackpad2ForWindows/tree/codex/human-friendly-haptic-controls). The optional low-battery alert was inspired by [Bananz0’s panel](https://github.com/Bananz0/MagicTrackpad2ForWindows/tree/winui3-port).
